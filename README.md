# MoviePilot 插件仓库（libremk66）

本仓库包含以下插件：

| 插件 | 说明 |
|---|---|
| [**实时硬链接+**（LinkMonitorPlus）](#实时硬链接linkmonitorplus) | 在 MoviePilot 内置「实时硬链接」基础上增加**已处理文件记录**，硬链被移动/入库后不再重复生成 |
| [**柯南集数映射重命名**（ConanRename）](#柯南集数映射重命名conanrename) | 按银色子弹数据站(sbsub)的**权威映射**把拆分版集号改名为 TMDB 集号（自动 `-partN`、自动特辑） |
| [**呀哈哈封面工坊**（YahahaCoverStudio）](#呀哈哈封面工坊yahahacoverstudio) | 第三方插件（作者 [呀哈哈](https://github.com/justzerock)）的**补丁版**：动态方案 1–4 也能各自设置「背景色来源」和「背景类型（纯色 / 纯色渐变）」 |

> 想看三个插件怎么串起来用？见下方 [柯南订阅整理流程（多插件流水线）](#柯南订阅整理流程多插件流水线)。

安装方式：MoviePilot → 设定 → 插件 → 添加插件仓库
```
https://github.com/libremk66/MoviePilot-Plugins
```

## 实时硬链接+（LinkMonitorPlus）

基于 MoviePilot 内置插件 **LinkMonitor 1.7.1**（作者 [jxxghp](https://github.com/jxxghp)）修改。

### 为什么需要它

原版判断"处理过没有"只有一个依据：**目标路径有没有文件**。于是：

```
1原文件/xxx.mkv  →硬链→ 2硬链/xxx.mkv →(改名/整理搬走)→ 媒体库/xxx.mkv
```
链接被搬走后目标就空了 → 下次同步**又链一次**，产生多余硬链、触发多余整理。

### 改成了什么

| 能力 | 说明 |
|---|---|
| 已处理记录 | `源文件路径 → {size, mtime, ino, target}`，落在 `/config/plugins/LinkMonitorPlus/linked.json` |
| 跳过判据 | 记录命中且文件未变 → 跳过（**目标被搬走也算处理过**） |
| 自动补登记 | 链接成功时登记；**目标已存在时也登记** → 升级后跑一次全量同步即可纳入存量 |
| 兜底判据 | 无记录时用 `st_nlink > 1` 判断 |
| 重新处理 | 文件被替换/重下（指纹变化）或目标目录改过 → 正常重链 |
| 清空记录 | 命令 `/realtime_link_clear`，或直接删 `linked.json` |
| 安静日志 | 跳过时只记日志、不发通知 |

### 安装配置

监控目录格式 `源目录:目标目录`，一行一个：
```
/你的盘/MOVIEPILOT/柯南/1柯南做种:/你的盘/MOVIEPILOT/柯南/2柯南硬链
```

> ⚠️ 与内置的 `LinkMonitor` 不冲突，但两个同时启用会各自处理同一批文件，建议只启用一个。

## 柯南集数映射重命名（ConanRename）

按 [银色子弹数据站](https://www.sbsub.com/data/) 的权威映射，把**拆分版集号**改名为 **TMDB 集号**。

### 为什么需要它

拆分版与 TMDB 的集号**偏移不是固定的** —— 每插入一次特辑/拆分集，后续偏移就 +1。实测同一批次内就有三种：

| 拆分版区间 | 偏移 | 集数 |
|---|---|---|
| 1201 – 1245 | −58 | 45 |
| 1246 – 1261 | −59 | 16 |
| 1262 – 1274 | −60 | 12 |

固定偏移（如"减 60"）的脚本会**静默改错** 1–2 集，轻则刮削错集，重则与已有文件撞名覆盖。

### 功能

- 从 sbsub 拉映射（地址可配，默认缓存 12 小时，失败退回旧缓存）
- **递归**扫描监控目录（默认 `.mp4/.mkv/.ts` 等），保留子目录结构 —— 解决"只扫顶层漏文件"的坑
- 一条 TMDB 集对应多个拆分版时自动 `-part1/-part2…`
- 映射里查不到的（如未被计入总集数的特辑）→ 用「补充映射」指定（`1262=S0E34`），否则移入 `_待人工/`，**不猜不改**
- **目标已存在则跳过并告警，绝不覆盖**
- 支持「仅预演」：先出清单再实际执行
- 每次实际改名写清单 `rename-YYYYMMDD.jsonl`（插件数据目录），可人工回滚
- **页面直接显示当前映射**：按「偏移区间」列出（拆分版区间 → TMDB 区间 → 偏移 → 集数 → 对应识别词）
- **识别词同步**（v1.1.0）：按当前映射的每个偏移区间各生成一条「区间限定」识别词，
  写回所选订阅的「自定义识别词」；可设独立同步 cron、可手动执行、可先预览规则。
  只动插件自己维护的注释区块，订阅里其它识别词不受影响；集号区间变了（新特辑插入）会自动跟着更新

### 推荐配置

```
监控目录: /你的盘/MOVIEPILOT/柯南/2柯南硬链
目标目录: /你的盘/MOVIEPILOT/柯南/3柯南重命名
处理方式: 移动
定时:     */10 * * * *
补充映射: 1134=S0E32
          1262=S0E34

启用识别词同步: 开
目标订阅:       <在插件里勾选你的柯南订阅>
识别词写法:     每个偏移区间一条
同步定时:       0 8 * * *
前定位词:       Conan\.S01E
后定位词:       \.1996
```

### 识别词同步写了什么

订阅的「自定义识别词」会变成这样（插件维护的区块，`#` 开头是注释、MP 会跳过）：

```
# >>> ConanRename 自动同步（插件维护，请勿手改）
Conan\.S01E(?=0*(?:12(?:4(?:6|[7-9])|5[0-9]|6(?:0|1)))(?:\D|$)) <> \.1996 >> EP-59
Conan\.S01E(?=0*(?:12(?:6(?:3|[4-9])|7(?:[0-3]|4)))(?:\D|$)) <> \.1996 >> EP-60
# <<< ConanRename 自动同步区块结束
```

每条规则只对**它那一段集号**生效，所以历史缺集搜索也能换算正确（固定偏移只在最新区间对，
这正是原来 `EP-60` 一条规则的问题）。手动写在订阅里的同形规则会被接管（避免抢命中）。

## 呀哈哈封面工坊（YahahaCoverStudio）

第三方插件「呀哈哈封面工坊」（作者 [呀哈哈](https://github.com/justzerock)，上游仓库 [justzerock/MoviePilot-Plugins](https://github.com/justzerock/MoviePilot-Plugins)）的**补丁版**，基于上游 **2.2.10**。

### 打了什么补丁

原本只有「静态方案」（自定义静态布局编辑器）能设**背景色来源**，动态方案只能吃全局配置，而且背景永远是"模糊主图混颜色"（方案 3 还固定带一层左→右变白渐变）。补丁后：

| 位置 | 说明 |
|---|---|
| 封面工坊 → 方案列表 → 动态方案的齿轮 → **动态方案 N 配置** | 新增「**背景类型**」：模糊主图（原行为）/ **纯色** / **纯色渐变**（左深右浅，用所选颜色生成） |
| 同一面板 | 新增「**背景色来源**」：从主图自动取色 / 手动指定 / 配置指定；选「手动指定」时出现「**手动颜色**」拾色器 |
| 纯色模式 | 背景 = 所选颜色**原样铺满**（不压暗、不加噪点、不做渐变），4 个动态风格都支持 |
| 纯色渐变模式 | 背景 = 用所选颜色生成的**左深右浅横向渐变**（插件原生「纯色渐变」同款算法），方案 3 原先只能靠全局开关碰运气，现在每个方案都能单独设 |
| 保存 | 随该方案的动态参数一起保存（`bg_style` / `bg_color_mode` / `custom_bg_color`），**每个动态方案可各不相同** |
| 页面模拟预览 | 自动跟随该设置，所见即所得 |

另外修了一个原生小毛病：**重载/停止插件后，动图预览会被内部遗留的"停止标志"挡住**（日志「检测到停止信号，跳过动图生成」），现在重载后预览直接可用。

静态方案、全局背景色设置的行为**保持不变**；未设置过的动态方案沿用原行为（模糊主图 + 全局背景色）。

### 上游更新后怎么重打

见 [`docs/呀哈哈封面工坊-上游升级后如何重打.md`](docs/呀哈哈封面工坊-上游升级后如何重打.md)，补丁文件在 [`patches/`](patches/)。

## 柯南订阅整理流程（多插件流水线）

> 柯南是**拆分版集号 ≠ TMDB 集号**的典型：订阅搜索、下载、改名、入库各由不同插件负责。
> 先在媒体库目录**之外**建一个「柯南」文件夹（下文用 `/你的盘/MOVIEPILOT/柯南/` 代表示例路径，
> 换成你自己的媒体盘与目录名）—— **不要放在 MoviePilot 已设置的自动整理目录下**，
> 否则文件会被 MP 的自动整理提前搬走、打断流水线。

```
建立柯南文件夹（不在 MP 已设置的自动整理目录下）
示例：/你的盘/MOVIEPILOT/柯南/          ← 结构示意，换成你自己的盘与目录名

① MP 订阅「名侦探柯南」
   关键词：Detective Conan S01 1996 1080p WEB-DL H264 AAC-ADWeb
   站点：观众
   保存路径：/你的盘/MOVIEPILOT/柯南/1柯南做种/
   识别词：Conan\.S01E <> \.1996 >> EP-60    ← 可用【MP插件 柯南集数映射重命名】自动更新
        ↓ 自动搜索 → 发给 QB 下载
② QB 下载 → /你的盘/MOVIEPILOT/柯南/1柯南做种/    （做种：文件一直留在这）
        ↓【MP插件 实时硬链接+】
③ /你的盘/MOVIEPILOT/柯南/2柯南硬链/
        ↓【MP插件 柯南集数映射重命名】
   重命名为 TMDB 集号（含 -partN、特辑 S00Exx）
④ /你的盘/MOVIEPILOT/柯南/3柯南重命名/
        ↓【MP插件 目录实时监控】
   刮削入库
```

| 环节 | 插件 | 建议配置 |
|---|---|---|
| ① 订阅 | — | 保存路径 `…/柯南/1柯南做种/`；识别词交给 ④ 的插件自动维护 |
| ② 下载 | QB（默认下载器即可） | — |
| ③ 硬链 | [实时硬链接+（LinkMonitorPlus）](#实时硬链接linkmonitorplus) | 监控目录 `…/1柯南做种:…/2柯南硬链`（一行一个） |
| ④ 改名 | [柯南集数映射重命名（ConanRename）](#柯南集数映射重命名conanrename) | 监控 `…/2柯南硬链` → 目标 `…/3柯南重命名`；方式「移动」；定时 `*/5 * * * *`；识别词同步定时 `0 2 * * *`（写法建议选**每个偏移区间一条**） |
| ⑤ 入库 | 目录实时监控（分身）（CloudLinkMonitor2） | 监控 `…/3柯南重命名:…/LINK/TV`；传输方式「硬链」；打开刮削/分类/刷新；定时 `*/15 * * * *` |

**为什么这么设计**

- **做种与入库解耦**：②③⑤ 三步全程用**硬链接**，`1柯南做种` 里的文件永远不动，PT 做种不受影响；想清理时删库里的硬链即可，源文件仍在。
- **原件留档**：④ 用「移动」把改名结果落到 `3柯南重命名`，每次实际改名都写清单 `rename-YYYYMMDD.jsonl`（插件数据目录），可人工回滚。
- **不猜不改**：映射里查不到的集号（多为此前未计入总集数的特辑）会被放进 `3柯南重命名/_待人工/`；用插件的「补充映射」显式指定（如 `1262=S0E34`）后才会自动处理。
- **识别词必须跟着映射走**：拆分版→TMDB 的偏移**会随特辑插入而漂移**（当前映射就有 61 个偏移区间），固定 `EP-60` 只对最新一段正确 —— 由 ConanRename 按区间自动生成并定时同步到订阅。
