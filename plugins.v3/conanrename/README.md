# 柯南集数映射重命名（ConanRename）

按 [银色子弹数据站](https://www.sbsub.com/data/) 的权威映射，把**拆分版集号**改名为 **TMDB 集号**。

解决的核心问题：拆分版与 TMDB 的集号偏移**不是固定的**（每次插入特辑/拆分集就 +1，实测同一批次内就有 −58/−59/−60 三种），
固定偏移的改名脚本会静默改错 1–2 集。

功能：
- 从 sbsub 拉映射（可配置地址，默认缓存 12 小时，失败退回旧缓存）
- 递归扫描监控目录（默认 `.mp4/.mkv` 等），保留子目录结构
- 一条 TMDB 集对应多个拆分版时自动 `-part1/-part2…`
- 映射里查不到的（如未被计入总集数的特辑）→ 用「补充映射」指定（如 `1262=S0E34`），否则移入 `_待人工/`
- **目标已存在则跳过并告警，绝不覆盖**；支持「仅预演」；每次改名写清单可回滚

建议配置：
```
监控目录: /你的盘/MOVIEPILOT/柯南/2柯南硬链
目标目录: /你的盘/MOVIEPILOT/柯南/3柯南重命名
处理方式: 移动
定时:     */10 * * * *
补充映射: 1134=S0E32
          1262=S0E34
```
